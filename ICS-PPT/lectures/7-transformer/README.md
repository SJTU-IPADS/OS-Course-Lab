第三部分的页序：生成时每采样一个 token 就追加到输入，整段重新运行会重做旧位置在每一层的计算，由此提出问题：这些结果会因新 token 而改变吗。为回答它，逐个看一层中的运算读取哪些位置：FFN、归一化与残差逐位置进行，只有注意力读取其他位置，而它受因果掩码限制。由此得到前缀不变性，旧位置各层的 K、V 可以逐层保存，即 KV cache。最后说明只缓存 K、V 的原因与 prefill、decode 两个阶段。

## 例子与数值的来源

画面上的文字与数值取自 3Blue1Brown 的 Manim 源码（[3b1b/videos `_2024/transformers`](https://github.com/3b1b/videos/tree/master/_2024/transformers)）与图文版的插图：生成例子的起始文本与 12 个候选的百分数（取整数部分）、分词的句子、聊天的系统提示词、线性回归的坐标、gensim 代码、tower 的近邻、性别方向的五对家庭关系词、Italy/Germany 与 sushi/bratwurst 的类比、复数方向的点积、Snape 一例的候选与概率、Softmax 与温度的输入、mole 与 tower 的短语、推理小说的首尾、交叉注意力的英法句子、crashed the car 与两个 Harry 的语境、John hit the brakes 一句的头类型、Frost 的诗。GPT-3 的结构数字（词表 50,257、嵌入 12,288、上下文 2,048、96 层、每层 96 个头、键查询空间 128、参数 175,181,291,520、27,938 个矩阵）与视频的参数账目一致。

视频中没有保存的内容不编造：GPT-2/GPT-3 与两种温度的故事文本画成文字条，只标出旁白说出的内容；cat 的近邻只标出旁白说出的 beast 与 monster。

注意力一例（a fluffy blue creature roamed the verdant forest）的分数写在 `diagrams/attn_data.py` 中，为手设的小数值：名词的查询与修饰它的形容词的键匹配，其余配对很小，creature 一列归一化后与视频相同，为 fluffy 0.42、blue 0.58。视频中的原始分数约为 ±100，未缩放。

注意力的表采用视频的方向：键为行、查询为列，Softmax 逐列进行。公式页以论文的形式 $\mathrm{softmax}(QK^T/\sqrt{d_k})V$ 为主（每个 token 占一行），并写出表的方向下的转置形式 $V\,\mathrm{softmax}(K^TQ/\sqrt{d_k})$。视频画面写作 $\mathrm{softmax}(K^TQ/\sqrt{d_k})V$，混用了两种方向，讲义没有照抄。

## KV cache 部分的依据与约定

- [Attention Is All You Need](https://arxiv.org/abs/1706.03762)：注意力与多头的计算，缩放的理由（§3.2.1）。
- [Language Models are Few-Shot Learners](https://arxiv.org/abs/2005.14165)：GPT-3 175B 的结构参数。
- [Hugging Face：Caching](https://huggingface.co/docs/transformers/main/cache_explanation)：因果推理中的逐层 KV cache。

符号：$d$ 为嵌入维数，$L$ 为层数。FFN 取两个矩阵的形式，中间维数为 $4d$。完整层采用 GPT 式 pre-norm。

## 图

图的源文件在 `diagrams/`，每个图（或每组动画）一个脚本，脚本名就是图名，运行 `sh diagrams/render.sh` 生成全部 `assets/*.svg`，生成的 SVG 不手改。公共部件：`svgkit.py`（绘图原语与配色）、`tk.py`（本讲的部件与样式约定：向量、权重矩阵、token、注意力表、概率条、参数账目、数学文字）、`attn_data.py`（注意力一例的数值）、`math_data.py`（检查用的向量运算）。`check_math.py` 检查输出矩阵的拼接等式，并用一个两层的小网络检查使用缓存与整段重算的结果相同，`check_bounds.py` 检查文字与方框是否越出画布。
