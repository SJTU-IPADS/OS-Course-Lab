## 跨平台

本节的命令在 x86-64 的 Linux、arm64 的 macOS 与 Windows 的 WSL2（Ubuntu）上都可以执行，
输出一致。原因是 nano-quant 是可移植的 C++17 程序：`CXX ?= c++` 在 Linux 上取 g++、
在 macOS 上取 clang++，Makefile 里的 `-ffp-contract=off` 与 `-fno-fast-math` 禁止编译器
把乘加合并为 FMA、禁止改变浮点运算次序，因此量化边界上的取整不随平台变化，
`nq-selftest` 的六行与写出的字节在三种机器上相同。

原生 Windows（不经 WSL2）需要 `make`、`xxd` 与 `python3`，这三者默认都不存在，
因此 Windows 上统一走 WSL2。

```bash

```

### 换机器上课前要核对的

更换模型后，张量数、字节数与推算出的超参数全部要修改。文件路径固定写在页面上，
换机器时先确认该文件存在，放置方式见 `../nano-quant/model/README.md`。

## 工具

`examples/sthead.py` 一个文件，两种模式：

```bash
python3 examples/sthead.py FILE          # 按顶层前缀分组，报张量数与字节数
python3 examples/sthead.py FILE PREFIX   # 列出该前缀下每个张量，输出中去掉前缀
```

第二种模式把查询的前缀从名字里去掉，是为了让 11 行输出各自不超过 62 个字符，
在幻灯片上不折行。输出是四列的纯文本，可以作为其他程序的输入。
