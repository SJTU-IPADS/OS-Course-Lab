## 用语与排版约定

与五讲正课讲义相同，完整的一份写在 `lectures/3-asm/README.md` 的同名一节，
改这份讲义时请一并维持。要点：

- **用语**：一律采用陈述性的技术表述，不使用比喻、口语化措辞，
  以及「不是……而是……」一类的对比句式，结论写成可以直接复述的判断句；
- **页标题必须说这一页要讲什么**，不用「上一页」「回顾：……」这类位置性说法；
  收尾页写「下一讲：……」是可以的；
- **正文只许向前回忆，不许向后预告**，演讲者备注同样遵守；
  向前回忆时按内容写（「`-Og` 那次编译」），不按位置写（「上一页」）；
- **自称统一写「本节」**，不写「本讲」；指别的讲次仍写「第一讲」「上一讲」；
- **`==标记==` 只在 `p.slide(...)` 里展开**，写进 `p.highlight(...)`、表格单元格
  会变成字面量；一页最多一个 `p.highlight`，不超过 66 个字符；
- 改完之后跑一遍 `--png`，检查有没有内容越过页底（1280×720 下 y≈706 是边界）。

## 上课时跑命令

```bash
python3 -m lecturekit.cli view lectures/exe-1-quant --watch
```

演示分两类：

- `examples/sthead.py` 读模型文件的头，本讲自带的工具，只做一件事——
  按前缀或分组把张量的 dtype、shape 与字节数打出来；

  `p.demo(files=...)` 的路径不能离开本讲目录，`command` 里的 `cd` 可以。

所有输出都是在这台机器上（i9-11900H，gcc 15.2.0，Python 3.14.4）实际执行得到的。

### 换机器上课前要核对的

第一部分整节依赖那个模型文件：

```bash
python3 examples/sthead.py ~/Downloads/model.safetensors
python3 examples/sthead.py ~/Downloads/model.safetensors model.language_model.layers.0.
```

换一个模型，张量数、字节数与推出来的超参数全部要改。文件路径写死在页面上，
换机器时先确认它存在。

## 工具

`examples/sthead.py` 一个文件，两种模式：

```bash
python3 examples/sthead.py FILE          # 按顶层前缀分组，报张量数与字节数
python3 examples/sthead.py FILE PREFIX   # 列出该前缀下每个张量，前缀已剥掉
```

第二种模式把查询的前缀从名字里去掉，是为了让 11 行输出各自不超过 62 个字符，
在幻灯片上不折行。输出是四列的纯文本，可以接给别的程序。
